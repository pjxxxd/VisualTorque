# VisualTorque — Behavioral Baseline on one A100

This notebook runs the behavior milestone before any activation probing. It uses direct, non-thinking prompts and scores the conditional likelihood of the complete legal replies `A`, `B`, and `C`. It is designed to resume safely after a Colab disconnect.

Run Qwen and Gemma **one at a time in separate runtimes**. First copy the inner `VisualTorque` project folder (the folder containing `toolkit/`) to `MyDrive/VisualTorque`.
