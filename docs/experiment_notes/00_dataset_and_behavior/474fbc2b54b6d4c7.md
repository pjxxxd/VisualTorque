# VisualTorque — Behavior Analysis v3

This notebook closes the behavioral evidence loop before any activation analysis. It uses the completed Qwen and Gemma prediction files; it does **not** load either model and does not require a GPU.

It adds four paper-facing audits: full-dataset image-versus-symbolic decomposition, heuristic/shortcut signatures, mirror equivariance, and a deterministic error gallery. All uncertainty and cross-model comparisons remain scene-level.

## 4. Full symbolic decomposition

This is the missing v2 table. It compares image and exact-symbolic inputs after applying the same six-permutation scene aggregation over all 2,100 scenes. A symbolic gain isolates an input-grounding contribution, but does not by itself identify a visual submodule.

## 原单元格 12

## 5. Heuristic signatures

The following analysis asks whether each model agrees with simple partial strategies, especially on scenes where a heuristic conflicts with the exact torque rule. Agreement is descriptive evidence of a shortcut signature; it is not a claim that the network literally implements that rule.

<a id="cell-14"></a>

## 原单元格 14

## 6. What predicts the model's signed evidence?

Five-fold out-of-fold ridge regressions compare an exact-physics predictor, a shortcut-only predictor set, and their combination. This is a predictive diagnostic, not a mechanistic decomposition. Per-problem-type torque correlations are also reported so that easy cue-compatible scenes cannot dominate the headline correlation.

<a id="cell-16"></a>

## 原单元格 16

## 7. Outcome mirror equivariance

For a true left-right mirror, semantic predictions should swap and the signed left-minus-right score should change sign. Mirror pairs are deduplicated by unordered scene pair before analysis.

<a id="cell-18"></a>

## 原单元格 18

## 8. Primitive mirror consistency

This audit swaps left-unit questions with right-unit questions, and left-distance questions with right-distance questions, across mirrored scenes. It uses only the previously completed image/symbolic control subset; zero overlap is reported rather than silently treated as success.

## 原单元格 20

## 9. Deterministic error gallery

The gallery is a renderer and failure-mode audit, not a mechanism for deleting inconvenient examples. Selection is deterministic and the chosen scene IDs are saved.
