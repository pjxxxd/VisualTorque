# 干预效果的事前预测：01 校准

默认先跑 Qwen-27B，之后可用全新运行时跑 Gemma-12B。需要 Drive 中已有 VisualTorque/toolkit 和历史 data/results。

这一轮预测指定干预的后果，不重复此前未获得增益的“预测自然错误”实验。两个模块分别检验答案内容迁移和来源距离 × 接收者距离。

层号均为从 0 开始的 decoder block 索引；只写入评分前最后一个 token 的 block 输出。

按顺序运行全部单元。校准和验证的 MODEL_KEY、RUN_ID 必须一致。运行另一个模型时重启运行时。

Qwen-27B 建议使用 96 GB GPU；Gemma-12B 可使用足够显存的 A100。程序要求完整 BF16，不自动改用量化或 CPU 卸载。
