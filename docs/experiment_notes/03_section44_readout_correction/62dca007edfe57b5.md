# E1｜三模型净力矩读出与数值修准

本 notebook 在同一数据协议下回答：**将外部读出的数值修到真实净力矩后，模型答案会不会随之改善？**

默认 `qwen9b`。依次用新运行时运行 `qwen9b`、`gemma12b`、`qwen27b`；27B 建议 80/96 GB 显存。
先用训练/开发数据冻结预测器，完成开发样本写入检查，再运行原 1,007 场景和 304 场景。
Qwen-9B/Gemma 优先复用原 ridge 和激活；27B 缺少同协议归档时自动采集原 discovery 清单并选 ridge。

新增数值修准明确使用真实净力矩，属于监督诊断。成功标准为**写回 BF16 后残差 ≤ 0.05**；失败记录保留，不能当作“修准了但答案不变”。
72 场景上各用 4 个固定随机/正交方向，以修准操作的**实际残差空间位移**匹配；失败也单列。
原五剂量在 304 场景保留。可核对并导入原始逐记录文件；缺少可验证记录时自动补采集，不从汇总表猜测。

旧测试状态的数值核对未通过时，会保存具体差异并自动重新采集全部测试状态，不放宽核对或修准阈值。

本修正版从头运行时输出到 `results/cross_model_readout_correction_v2/`，避免与旧版本代码锁冲突。已经停在旧版 12/15 单元格的运行，优先使用配套的单元格补丁，可以保留当前模型和已拟合读出器继续执行；无需重跑前面步骤。
每个阶段按场景恢复，协议、代码、模型或图片改变时拒绝混入旧记录。
前置：Dataset v1、原 `behavior_comparison_v3/activation_pilot_manifest.jsonl`、两小模型的 discovery 归档。所有新增结果尚未执行。
