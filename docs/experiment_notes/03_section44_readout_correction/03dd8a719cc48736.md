# VisualTorque — Causal Torque-Direction Steering on one A100

This notebook tests whether changing only the frozen net-torque readout direction at
the selected decoder layer causally changes the model's answer. It is a frozen
exploratory intervention after the representation confirmatory and specificity
analyses; it is not part of the original preregistered test.

Primary intervention:

- Refit the already selected Ridge probe on probe_train plus probe_dev.
- Convert its standardized coefficient into the minimum standardized-norm hidden-state
  perturbation that changes decoded torque by a prespecified amount.
- Add that perturbation only to the final prompt token at the frozen decoder layer.
- Measure the dose response of the semantic left-minus-right answer margin.

Controls:

- zero-dose hook parity;
- 24 deterministic probe-orthogonal directions with matched standardized norm;
- the identical torque perturbation applied one layer earlier and one layer later;
- paired toward-gold versus away-from-gold effects on non-balanced scenes.

Run once for Qwen and once for Gemma in fresh A100 runtimes. The run is append-only and
resumable through atomic JSON shards. A successful result establishes that this
direction can causally influence the output, but does not by itself prove natural
mediation, a unique torque circuit, or on-manifold computation.
