# VisualTorque — Representation Specificity and Additive-Confound Analysis

This CPU-only notebook asks whether the frozen Qwen and Gemma activation probes
contain signed-torque information beyond ground-truth additive scene statistics.
It consumes the already completed discovery and confirmatory artifacts; it does not
run either multimodal model again.

Status of this analysis: **frozen exploratory follow-up after probe_test was opened**.
It must not be described as part of the original confirmatory protocol. The analysis
definitions below are locked before the saved activations and test predictions are
read.

Primary analyses:

1. Additive features versus activation versus additive-plus-activation.
2. Cross-fitted partialling-out of additive features from both torque and activation.
3. Exact additive-matched groups with identical additive feature vectors but different
   weight-distance pairings and different torque.
4. Paired Qwen–Gemma bootstrap on the same probe_test scenes.

The strongest defensible conclusion is conditional information or binding
sensitivity. These analyses still do not prove a causal circuit or causal use in the
model's final answer.

## 3. Conditional information beyond additive primitives

Cross-fitted activation predictions prevent an in-sample high-dimensional probe from
leaking into the low-dimensional stacker. The stronger partialling-out analysis
cross-fits nuisance regressions from additive features to both torque and every
activation dimension, then applies the unchanged discovery Ridge alpha.

## 4. Exact additive matching and a strict binding subset

The primary matched group has exactly the same six additive features but at least two
distinct net torques. Consequently, every linear additive model must give the same
prediction within a group. This isolates information beyond that additive vector, but
does not guarantee that the primitive multisets are identical.

A stricter descriptive subset additionally holds the per-side unit multiset and
distance multiset fixed, so only their pairing changes. Dataset v1 contains few such
test pairs; the notebook reports them without treating them as a well-powered primary
test.
