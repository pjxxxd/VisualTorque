# VisualTorque — Activation Discovery on one A100

This notebook captures residual-stream states for the **frozen 254-scene discovery manifest** and runs train/dev linear probes. It never reads `probe_test`, never chooses an intervention site from test data, and does not make a causal claim.

Run it once for Qwen and once for Gemma in fresh runtimes. It captures all six A/B/C permutations, saves only eight decoder depths at the exact final prompt position used for answer scoring, writes resumable Drive shards, and uses the six-permutation scene mean as the primary physical representation.

## 4. Train/dev discovery probes

Continuous physical probes use the scene-mean state. Outcome classification also uses scene means. Correct-label and predicted-label probes use the original permutation-level states but preserve scene-level train/dev separation. Hyperparameters and layer sites are selected on `probe_dev`; this notebook does not evaluate `probe_test`.
