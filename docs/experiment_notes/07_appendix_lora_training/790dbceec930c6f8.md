# VisualTorque — Qwen3.5-27B Post-LoRA Torque-Control Stress Test

上一轮 blind causal validation 的六个预设 gate 通过了五个：LoRA 的盲测行为改进、局部层窗贡献、L50 state 的充分性与必要性，以及 L42 torque direction 到 L50 outcome probe 的传播均成立；唯一失败的是 **L42 torque direction 对最终答案的直接控制**。

本 notebook 只处理这个未解决问题，不重新训练、不重新选择原论文的 L42/L50 hypothesis，也不使用 blind-confirmatory 标签重新拟合 probe。

实验采用严格的两阶段设计：

1. **route-development：**使用上一轮已经接受过干预的 24 个 weight-conflict scene，比较 3 个层位（L38/L42/L46）、3 个 token group（final / visual / all attended）和两种只在原 probe-train 上拟合的物理方向（rank-1 net torque / rank-2 side torque）。每个 scene 只使用一个 label-balanced permutation。
2. **intervention-confirmatory：**冻结最优候选后，只在剩余 24 个从未接受过因果干预的 conflict scene 上测试；每个 scene 使用 A/B/C 各一次，共 72 个 prompt。
3. **方向特异性：**确认阶段使用 32 个与两个物理方向均正交、范数匹配的随机方向。随机方向数量预先锁定，使最小经验单侧 p 值为 1/33≈0.0303。
4. **可解释的正控制：**在 L50 final token 上干预冻结的 outcome-probe left-minus-right 方向。如果这个方向也不能控制答案，则不能把 torque 方向失败解释成机制不存在。

主结论单位始终是独立 physical scene，而不是相关的 option permutations。该实验识别的是受控 hybrid intervention 下的方向性控制，不等于唯一 circuit，也不证明显式乘法。

## 5. Frozen-gate analysis

Direct torque control requires a positive scene-level slope, a positive −4→+4 contrast, empirical superiority to the 32 random directions, and positive effects in all three gold-label strata. L50 outcome-direction steering is a mandatory positive control.
