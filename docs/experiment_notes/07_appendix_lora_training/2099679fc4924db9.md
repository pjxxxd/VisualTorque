# VisualTorque：冻结通路变化的边界与尺度审计（CPU v1）

上一轮 v3 已显示：行为改善与三个 Native 冻结方向上的特异传递效应减弱同时出现。本轮直接读取 **v3 已完成的结果目录**，回答：这种变化是否出现在训练/开发未见几何中？是否跨两种答案映射？随机轴、自钳制及相对干预尺度给出了什么解释线索？

**无需 GPU、模型权重、重新训练或推理。** 在 Colab 选择普通 CPU 会话，Run all，挂载原 Google Drive 即可。默认读取 `VisualTorque/results/qwen27b_base_vs_lora_frozen_handoff_comparison_v3/`；只有工程位置不同才需修改第 2 阶段的路径。保留完整 v3 结果目录，包括根目录的记录文件与 `analysis`；不用复制训练 adapter。不要将本 notebook 指向 v1/v2 结果。

分析先核对完成记录和文件哈希，从 clean/patch 原始表重新计算全部指标，并核对 v3 的主结果。独立单位始终是**物理配置 family**；两种映射先在 family 内平均。未见几何名单来自 v3 在推理前冻结的列表，不按 LoRA 结果重新分组。

本轮是在看过 v3 主结果后进行的**同一数据集次级审计**，不是新的盲测或独立确认。边界、交互及分解表均使用描述性的逐项 95% family-bootstrap 区间，不增加新的“显著通过”判据。v3 原三项主检验的 Holm p 值原样保留，并核对其效应估计。

**解释边界：**答案 margin 是正确物理侧与相反侧的 log-probability 差，没有准确率那样的固定上界。较大的自然 margin 本身不证明“天花板解释”；激活范数也不是完整的有效剂量。尺度与效应的相关性不能证明变化被解释掉，亦不能证明坐标旋转或通路消失。

添加向量的相对大小与轴钳制分开分析：轴钳制会先将轴归一化，不能把轴范数当作钳制强度。本轮额外读取钳制实际移除的投影系数，分别报告目标轴与随机轴的移除量。

输出到新的 `results/qwen27b_frozen_handoff_boundary_scale_audit_v1/`，最后显示完整中文报告，并在旁边生成同名 `.zip`。将**执行后的 notebook 或这个 ZIP**发回即可查看全部关键结果。
