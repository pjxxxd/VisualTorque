# VisualTorque — Qwen3.5-27B Post-LoRA L50 Causal-Subspace Decomposition

前两轮实验形成了一个精确边界：

- LoRA 显著降低 weight shortcut；
- same-prompt **完整 L50 state** 对行为改进具有充分性和必要性；
- L42 torque direction 可以线性改变 L50 outcome-probe score；
- 但扩大剂量、搜索邻层与 token group、加入 rank-2 physical direction 和 32 个随机方向后，一维/二维 torque steering 仍不能控制最终答案；L50 outcome direction 的正控制则成立。

因此，本 notebook 不再继续调单一 probe vector，而是检验：

> LoRA 在 L50 写入的行为改进，是否存在于一个可复现的低维 causal subspace；这个子空间主要像 permutation-invariant scene state，还是像 option-mapping-dependent response code？

为避免在已经查看过的场景上验证新假设，本 notebook 生成 **48 个全新的第二代 blind weight-conflict scenes**，排除 Dataset v1、上一轮 216 个 blind scenes 及它们的镜像。24 个 scene 用于学习子空间和选择最小 rank；另外 24 个 scene 在选择文件冻结后才进行模型前向。

核心干预对每个 test prompt 的真实 same-prompt 差值

\[
\Delta h_{50}=h_{50}^{LoRA}-h_{50}^{Native}
\]

进行正交分解。Native recipient 接收投影后的 \(P\Delta h\)（充分性），LoRA recipient 移除同一分量（必要性）。完整差值、所选子空间、正交余量、outcome/torque probe、scene-shared、mapping-residual，以及 32 个同维随机子空间全部使用完全相同的 patch 接口。

这仍然是 hybrid intervention：通过只能说明某个低维状态子空间在该干预下携带因果作用，不等于唯一 circuit，也不证明显式乘法。

## 4. Scene-level causal decision

The main gate requires independent replication of the full patch, positive selected-subspace sufficiency and necessity, at least 80% recovery of both full effects, superiority to matched-rank random subspaces, and robustness to A/B/C answer placement.
