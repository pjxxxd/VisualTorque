## 推理前冻结的范围

- **24 个新物理家族**，2 个镜像、6 个接收映射、2 个来源背景 × 2 个来源映射。来源加两块前后真实答案与正确字母不变；接收场景分为应翻转和应保持两类。
- 最大单侧 8 块，距离 **1–8 格**，画布仍为 896×448，刻度扩展为 8。历史 1–6 格范围排除已用几何后仅余 8 个完整家族，不足 24；本协议在新模型输出出现前扩展距离范围。**这是扩展几何范围的独立确认，不能称原分布复现或训练分布总体评估。** 图像、规则和统计对两个模型相同。
- 排除原始 Dataset v1 全部单堆几何、已列历史清单、原 24 个物理更新家族及其镜像；训练／开发清单与 dataset fingerprint 一并核验。新增其他历史暴露可填入 `EXTRA_EXPOSURE_MANIFESTS`，必须在首次运行前配置。若池不足，报错而不缩小家族数或放宽排除。

## 2×2 交叉：分量库来源 × 接收模型

对库来源模型 s，L48 最终提示 token 的原始来源差记作 Δh_s；接收 before 状态记作 h_s，自然 before→after 差为 g_s：

`v_s = ||h_s|| / ||source_before_s|| × Δh_s`

`A_s = <v_s,g_s>/<g_s,g_s> × g_s`，`R_s = v_s − A_s`。

随后将库内向量 p_s 注入接收模型 r：

`p_(r←s) = ||h_r|| / ||h_s|| × p_s`。

因此，**固定库来源、条件和输入时，两个接收模型使用同一方向和相同的请求相对范数**。两个库之间的原始分量范数不强制相同；库来源差异混合方向、分量比例和幅度，不能称纯角度变化。对角线使用各模型自身更新，保持上一轮分解规则；对角线模型差同时包含更新构造与接收响应改变。固定库的模型差更直接测量接收响应变化。

每个库、每个来源配对包含 full、half-full、A、R、A+0.5R、两个 random-A、两个 A+旋转-R。随机 A 与 A 等请求范数；旋转 R 保持本库自然轴投影和 full 请求范数。每个接收输入另有共享 zero、0.5g、g。共 **75 条件／输入／模型；86,400 次干预 + 3,072 次 clean 捕获**，技术检查另计。运行耗时由实际 ETA 给出，逐条件保存，重启 Run all 可续跑；旧结果只读。

完整更新不使用目标 after；A/R 分解使用目标自然反事实信息。因此本轮是目标辅助机制诊断，不是可部署的盲迁移方法。跨库 A 只沿库来源的 g_s，未必沿接收模型自身 g_r。L48 分解恒等式不作实证；主要看输出和 L49/L55。

## 六项主检验（flip；双侧；统一 Holm 校正）

1. Native 自身库 A−zero。
2. Native 自身库 A−平均 random-A。
3. 对角线模型差：LoRA 自身库与 Native 自身库的 A 特异效应之差。
4. 固定 Native 库：LoRA−Native 的 A 特异效应差。
5. 固定 LoRA 库：LoRA−Native 的 A 特异效应差。
6. 对角线模型差：两模型 full−A 效应之差。

独立单位是家族；先平均镜像、映射、来源背景和随机重复。1–2 为旧 Native 假说在新范围的确认，3–6 直接检验模型差；不以一方显著另一方不显著推断模型差。六项并非统计独立，Holm 不要求它们独立；符号翻转依赖零假设下家族差值的对称性。95% bootstrap CI 为逐项区间。次级输出含全部 2×2 单元、交互、直接配对准确率、stable 损伤、下游距离、来源预测稳定、所有 BF16 阈值和逐家族／映射边界；不新增确认性 p 值。

干预的准确率以目标 after 场景的真实答案评分；注入时仍输入 before 图片。它衡量反事实更新是否实现，不是原始 before 任务的普通准确率提升。真实 before／after 图片的自然准确率另外列出。shared g/2 与 g 每个接收输入只计一次，不能扩成多个来源配对样本。

每次实际 BF16 注入逐元素核验。1%、2%、5% 的实际相对范数误差敏感性使用两个模型共同满足的同一配对掩码，不挑有利阈值；不修改已运行的剂量。half-full 与 A+0.5R 不能证明 A 的最优剂量或排除所有非线性。状态接近、margin 和准确率分开报告；不以不显著证明等效或残余无用。
