# VisualTorque — Qwen3.5-27B Base vs LoRA Distance-Factorial Audit

已有结果说明 LoRA 在总重量相同、必须依赖距离的 blind-v3 场景上明显优于 Native，但尚不能区分两种机制：

1. LoRA 是否更准确地**读取距离**；
2. 或者 Native 与 LoRA 都已编码距离，而 LoRA 只是更好地将距离用于 torque 和 outcome。

本 notebook 先完成行为诊断，不在看到结果后选择层或做 activation intervention。它包含两个预先冻结的 track：

- **In-range SFT-unseen**：44 个 Dataset v1 `probe_test` single-stack 几何，全部未进入 SFT；重新使用两种新风格渲染。距离仍在训练世界的 1–6 范围内。
- **Distance extrapolation**：44 个全新 single-stack 几何，至少一侧距离为 7 或 8；所有几何均在 Dataset v1 范围之外。

每个 track 覆盖六类距离诊断：等重量距离决定左/右结果、重量—距离冲突左/右、不同因子但等 torque、以及小净力矩边界。每个 scene 同时测试：

- 左/右距离直接读取，并让正确数字分别位于 A/B/C；
- 左/右重量、左右 torque、net torque；
- 三个 Latin-balanced outcome 排列；
- 额外的 symbolic outcome/net-torque 对照，用于区分视觉读取与后续物理组合。

主诊断不是“所有指标必须一起提高”，而是区分：距离读取改善、下游距离使用改善、两者都改善，或证据不足。
