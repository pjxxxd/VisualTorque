## 原单元格 0

# VisualTorque — Qwen3.5-27B Post-LoRA L50 Frozen Rank-4 Blind-v3 Replication

上一轮在完全 held-out 的 strict weight-conflict scenes 上发现：由 development 数据冻结的 L50 `joint_svd_rank4` 子空间，在 Native→LoRA 与 LoRA→Native 两个方向分别恢复完整 L50 state patch 约 91% 和 90% 的 correct-margin 效应。它通过了完整 patch、充分性、必要性、80% 非劣性、A/B/C permutation 和原始随机对照；唯一未通过的是 LoRA 必要性方向的单位投影范数随机效率检验（32 个随机子空间，经验 `p=2/33=0.0606`）。

本 notebook **不重新训练、不重新选层、不重新选 rank，也不重新学习主子空间**。它在任何 blind-v3 模型输出产生前，冻结上一步保存的 L50 rank-4 basis 和全部判据，然后：

1. 生成 52 个全新的 multi-stack scenes，排除 Dataset v1、blind-v1、blind-v2 及镜像；
2. 保留 24 个 strict conflict scenes 作为预注册主检验，并额外覆盖 weight/outcome 的全部 3×3 组合，检查机制是否只在冲突分布有效；
3. 每个 scene 使用三个 Latin-balanced A/B/C 排列；
4. 比较 Native 与 LoRA 的准确率、weight-following、balanced outcome 与 permutation 稳定性；
5. 在 L50 比较完整差值、冻结 rank-4、其正交余量、scene-shared 与 mapping-residual；
6. 使用 99 个同维、同 parent span 的随机子空间，提高经验检验分辨率到 0.01，并同时报告原始效应与单位投影范数效率。

主机制结论只使用预先指定的 24 个 strict conflict scenes。其余 28 个 scenes 是外部分布/机制边界审计，不参与主 gate。
