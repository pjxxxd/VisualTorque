# VisualTorque — Strict Held-Out Evaluation of Qwen3.5-27B Before and After LoRA

This notebook is **evaluation-only**. It never constructs a training dataset, never calls a trainer or optimizer, and never performs a backward pass. The model receives only examples whose frozen Dataset v1 split is \`probe_test\`.

The comparison has two complementary parts:

1. **Primary classification result:** candidate-scored semantic accuracy over all six A/B/C permutations for every held-out scene. Existing complete shards from the training run are identity-checked and reused by default; missing results are recomputed.
2. **Answer-generation sanity check:** deterministic free generation with exact-format and parsed-answer accuracy. This uses one preregistered, label-balanced permutation for every test scene plus all six permutations for the balanced 3 × 3 shortcut subset.

The primary test is the 3 × 3 balanced subset of total-weight cue × physical outcome. The natural full test, multi-stack scenes, per-class recall, confusion matrices, weight-conflict behavior, permutation robustness, paired bootstrap intervals, and exact McNemar tests are also reported.

> **Important test-set policy.** \`probe_test\` was excluded from LoRA gradients, so it measures held-out generalization. However, its results have already been viewed in the training notebook. Do not tune LoRA hyperparameters after inspecting these results and still call this set blind. For a final confirmatory paper result, freeze the present adapter and evaluate once on a newly generated, independently seeded/style-shifted test set.

## 4. Paired analysis and handoff

All headline comparisons are paired by scene. The balanced 3 × 3 subset and weight-conflict scenes are emphasized because overall weight-following can rise mechanically when weight and the correct outcome agree. Confusion matrices, macro-F1, balanced accuracy, balanced-class recall, answer-format compliance, permutation stability, bootstrap intervals, and exact paired tests prevent a single aggregate accuracy from hiding failure modes.
