# VisualTorque — Qwen3.5-27B Post-LoRA Blind Causal Validation

这个 notebook 在不重新选层的前提下，验证上一轮 discovery 提出的机制假设：

- Native 已经编码净力矩，但没有稳定把它路由到答案；
- LoRA 的关键改变位于净力矩层与 outcome 层之间；
- 对冻结的净力矩方向做干预，应当可预测地改变 L50 outcome state 和最终答案。

Protocol 在任何新模型输出产生之前锁定。确认集包含 216 个全新 multi-stack geometry，严格排除 Dataset v1 中已有 geometry 及其左右镜像；九个 weight-cue × outcome cell 各 24 个。每张图使用两个从未训练过的渲染风格之一。完整行为测试使用六种 A/B/C permutation；因果实验使用从两个非平衡重量冲突 cell 预先选择的 24 个 scene，每个 scene 使用 A/B/C 各一次的三个 permutation。

本 notebook 检查三类因果证据：

1. 等宽三层 LoRA-window ablation：哪个局部层窗对改进是必要的；
2. Native ↔ LoRA same-prompt state patching：L42/L50 状态是否足以传递或移除改进；
3. 冻结 L42 net-torque probe direction 的双向 dose-response，以及它是否通过冻结的 L50 outcome probe 传播。

这些实验仍然是受控 hybrid interventions，不等于识别唯一 circuit，也不证明显式乘法。

## 2. Freeze behavior and causal manifests

The behavior manifest contains all six answer permutations for all 216 scenes. The causal manifest is a metadata-only subset of 24 non-balanced weight-conflict scenes, with one A-, B-, and C-labeled prompt per scene.

## 4. Frozen-site causal tests

Clean states are cached once. Self-state patches must reproduce the clean logits. Local adapter ablations, same-prompt cross-model state patches, and direction sweeps are all resumable per example.

## 5. Scene-level confirmatory analysis

All three option mappings are averaged before treating a physical scene as an independent causal unit. Confidence intervals and sign-flip tests therefore operate over 24 scenes, not 72 correlated prompts.
