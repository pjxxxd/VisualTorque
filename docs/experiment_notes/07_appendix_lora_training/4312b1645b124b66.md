# VisualTorque — Qwen3.5-27B Post-LoRA L50 Metric-Route Blind Causal Validation

前一个独立行为实验发现：LoRA 能在“相同 ordinal cues、相反 outcome”的 matched pairs 上根据真实幅度翻转答案；它改善相对距离、单侧 torque 和 torque relation，却没有改善绝对距离或精确 net torque。扩大后的 near-boundary 结果既没有显著改善，也没有复现显著恶化。

本 notebook 不从已经观察过结果的场景中挑选成功或失败案例。它在模型推理前：

1. 冻结先前 development-only 学得的 L50 `joint_svd_rank4` basis；
2. 生成 44 个全新 single-stack 场景，至少一侧距离为 11 或 12，并排除所有已有数据及镜像；
3. 冻结 12 对 ordinal-matched outcome-flip、12 个 near-boundary、8 个 exact-balance 场景；
4. 对每个场景同时测试 `outcome` 与 `torque_relation`：前者使用 A/B/C，后者使用不重叠的 X/Y/Z；两个任务都采用三个 Latin-balanced 映射；
5. 在 Native→LoRA sufficiency 和 LoRA→Native necessity 两个方向，比较 full L50 delta、冻结 rank-4 分量、正交补以及 31 个同 rank 随机子空间。

核心问题是：冻结的 L50 rank-4 子空间究竟是共同中介 torque relation 与 outcome，还是只作用于最终 categorical decision。near-boundary 与 exact-balance 只用于检验机制边界，不能从失败案例中重新拟合 basis、层或 rank。
