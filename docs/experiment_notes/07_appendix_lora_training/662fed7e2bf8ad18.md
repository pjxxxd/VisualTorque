# VisualTorque — Native vs LoRA：冻结通路的直接配对比较（v3）

**v3 修复：**v2 从 PostLoRA 安装单元继承了 `torch.backends.cuda.matmul.allow_tf32 = True`；原 Native notebook 没有这项加速设置。Qwen3.5 在当前 Torch fallback 路径中包含 FP32 矩阵乘法，因此模型权重为 BF16 并不意味着 TF32 设置无关。本版在加载模型前明确设置 `highest` / TF32 关闭，并在每次前向计算及缓存入口检查设置，避免重新使用错误精度下的方向。增加 bare Native 与关闭 LoRA 后 L48/L49/L55 最后 token 状态的一致性检查，并保存数值环境与模型实现信息。此设置差异已在代码中确认；它能否完全解释上传结果的范数漂移，仍由 GPU 上的历史校准验证。

**保留原校准门槛：**逐家族比较 128 个 L49/L55 差值范数、128 个原始答案分数及映射，使用历史固定方向强度，完整保存诊断。未放宽 v2 的 1% 中位数 / 3% 逐家族范数容差；明显偏差仍停止。新输出使用独立 v3 目录，不读取 v1/v2 方向或干预缓存。

**这一轮回答：同样的物理场景中，微调改变了哪些答案，以及 Native 已验证的 L48 → L49 → L55 → 答案传递如何变化？**

沿用 Native 独立复现中冻结的 **32 个物理配置、128 张图片、每张两种答案映射**；同一个 Qwen3.5-27B BF16 checkpoint，通过关闭/开启现有 LoRA adapter 对照。使用完全相同的 Native 方向、剂量、随机轴和原有 14 类干预；左侧沿用其中 9 类。默认共 **512 次自然回答 + 5,888 次干预评分**，另有方向重建和自检。不训练、不重新筛选成功案例、不在当前样本上拟合方向。

这是一轮**已有 Native 队列的机制复核**，不是新的盲测。主分析固定在原 `right_error/right` 场景，检验 LoRA−Native 的三个配对效应差；其他侧别、正确队列、答案映射及训练集未见几何子集用于边界分析。原队列按 Native 行为选出，结论限于这一队列及当前 adapter，不能作为总体准确率或训练随机种子间的结论。

运行前检查 SFT train/dev 的**完整几何与左右镜像重叠**；不把换颜色当作未见物理。全部原队列保留，未见 train/dev 的子集独立报告，不根据本次 LoRA 表现换样本。独立统计单位是物理配置，图片、映射与模型状态不增加样本量。

**运行方式：**在 Colab 96 GB GPU 环境打开本 v3，建议先重启会话，再沿用已有 Google Drive `VisualTorque` 工程按顺序 Run all。不要从旧 v2 的报错单元继续执行；无需重训或删除旧结果。第 2 阶段会显示 `float32_matmul_precision: highest` 与 `tf32_matmul: False`，第 8 阶段保存关闭 LoRA 前后的分数和隐藏状态检查，第 9 阶段重建并校准全部方向。第 3 阶段在加载模型前列出缺失的前序文件；需要 Native independent replication、它原来的方向来源、SFT adapter/manifests 和 Dataset v1。新输出目录为 `results/qwen27b_base_vs_lora_frozen_handoff_comparison_v3/`。逐模型/场景/映射保存，可重新 Run all 校验后续跑。

如果第 9 阶段仍停止，完整诊断保存在上述目录的 `direction_rebuild_diagnostics.json`、`direction_rebuild_observations.json`、`runtime_lock.json` 和 `analysis/direction_norm_calibration.csv`。这表示还有未定位的环境差异，不能通过删除断言或手动缩放来证明方向复现。修复代码已做离线验证，本地未运行 27B GPU 推理。

数值设置依据：[PyTorch float32 matmul precision](https://docs.pytorch.org/docs/main/generated/torch.set_float32_matmul_precision.html)；[Qwen3.5 Torch fallback 实现](https://github.com/huggingface/transformers/blob/main/src/transformers/models/qwen3_5/modeling_qwen3_5.py)。

**解释边界：**冻结的 Native 轴在 LoRA 中效应减弱，既可能涉及坐标变化，也可能涉及剂量尺度或已答对后的上限；不能直接说通路消失。干预制造的传递效应也不等于自然回答已通过该路径计算乘法。不得把不显著当成前后等价。新的独立物理配置确认，留待这轮确定具体变化后另做。

## 冻结坐标：不在 LoRA 上重拟合

L48 使用原 discovery 的 PLS4 prototype；L49 和 L55 使用原方向支持集在 Native 下重建。逐家族范数、答案分数与映射必须通过历史校准，再固定为历史干预强度并保存张量。数值校准不等于证明历史向量逐元素相同，后续仍须检查 Native 干预效应的历史复现。所有钳制以**当前被测模型自己的未干预状态**为基线，不把 Native 干净状态错误地当作 LoRA 干净状态。

## 直接比较前后效应

记 M 为正确物理侧相对相反侧的 log-probability margin，ΔM 为干预后相对本模型 clean 的变化。

例如 L48 经 L49 的方向特异损失 = `[ΔM(upstream) − ΔM(upstream+L49 clamp) + ΔM(self L49 clamp)] − [ΔM(upstream) − ΔM(upstream+random L49 clamp) + ΔM(self random L49 clamp)]`。

主统计比较的是**这一损失在 LoRA 与 Native 之间的差**，不是“一个显著、另一个不显著”。不使用不稳定的除以总修复量的中介比例。
