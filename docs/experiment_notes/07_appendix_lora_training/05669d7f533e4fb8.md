### 数学口径

`p` 是上游干预相对**该模型自身 clean 状态**的位移，在已冻结、指向正确侧／正确答案代码的单位轴上的投影。主展示固定 Native 注入方向、relative +1；Native / LoRA 接收模型都用同一指定坐标来源比较。坐标轴本身可随映射改变，因此跨映射平均是**有向标量的平均**，不是把隐藏向量直接相加。负剂量的投影仍使用原正确答案方向，不重新翻转坐标。

- `P = mean(max(p,0))`，`N = mean(max(-p,0))`；净投影 `S=P-N`，绝对量 `A=P+N`。
- 总抵消量 `A-|S|`。先平均映射、再平均镜像、最后平均家族，可以将其精确分解为三个非负部分；同时输出相反平均顺序。这个分解依赖平均顺序，不能据此证明映射或镜像“导致”了机制变化。
- 所有模型差值均按同一物理 family 配对。非线性的抵消量／比率在每次 family bootstrap 内重新计算，不把平均比率当整体比率；分母为零时留空。
- 精确正负分解不设阈值；符号翻转另外使用预先列明的 `0 / 0.1 / 0.5 / 1.0` 投影单位阈值做敏感性分析。这些阈值不是已验证的数值噪声界。

**证据定位：**这是看过结果后的探索性分析。原六项主检验重新复核，沿用原 Holm 校正；新增表只给逐项 95% family-bootstrap 区间，不新增确认性通过判据。失败家族按 LoRA 结果筛选，只做案例描述，不用这些子组推断自然因果中介。镜像／映射／干预次数不是额外独立样本。

**解释边界：**`clean_margin` 是正确侧相对相反侧的两候选 margin，不包含第三个 balanced 候选的竞争，不能用 margin 正负替代三分类正确性。紧凑包没有原始 logits、轴张量或 clean 张量，不能重建前向计算；不拟合新轴、不优化剂量、不声称通路消失、算法改变或自然行为中介。
