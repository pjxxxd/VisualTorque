# VisualTorque — Qwen3.5-27B Native vs LoRA Mechanism Discovery

这一步不是再次汇报 test accuracy，而是回答：LoRA 提升后，模型内部对“总重量”“力矩”和“最终答案”的表征在什么深度发生了变化？

本 notebook 的规则：

1. 模型始终处于 inference-only；不做梯度更新，不继续训练 LoRA。
2. 线性 probe 只在 probe_train 上拟合，只用 probe_dev 选层。模型前向过程中不会构造 probe_test prompt。
3. probe_train 中曾被 LoRA SFT 使用过的 scene 会标记为 seen_in_sft；主要选层结论来自从未参加 SFT 的 probe_dev。
4. native 与 LoRA 使用完全相同的 prompt、A/B/C 映射、图像、层位置和候选打分。
5. 产物是“机制假设”和冻结层位，不是因果证据。下一步要在新盲测集上做 activation patching / intervention 才能声称机制被修复。

开头的 coverage audit 只读取 Dataset v1 元数据来回答 test set 是否全面；它不把 test 图像或问题送入模型。
