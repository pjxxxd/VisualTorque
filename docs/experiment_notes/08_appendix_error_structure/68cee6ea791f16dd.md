# VisualTorque — Qwen-27B Query-Conditional Torque Use

The independent terminal-bridge experiment found positive and balanced physical-donor effects, but a same-outcome/different-torque control was equally or more effective. This targeted follow-up tests whether the apparent discrepancy is caused by the question itself: does the model use a torque-specific state when explicitly asked for torque, but rely on a generic outcome state when asked which side moves down?

The exact same 29 frozen base/weight/distance triplets are evaluated under two prompts: `side_torque` and `outcome`. A metadata-only control has the physical donors' outcome but a third, distinct queried-side torque. The primary estimand is the within-triplet difference-in-differences between physical-minus-control effects under the two questions. The primary L48 `pre-options` mask contains only causal text positions that occur before A/B/C options; previously frozen L48 text/options and L48/L55/L63 answer positions are retained as supporting sites. There is no layer or component search.

This is a targeted within-support mechanism test, not an independent replication. A positive result must subsequently be replicated on another model or new support.
