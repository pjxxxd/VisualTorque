# VisualTorque — Qwen-27B Net-Torque Aggregation and Invariance

This independent, fixed-site experiment fills the missing edge between side torque and net torque. It creates scene-disjoint natural 2×2 quartets: a balanced base, a left-only edit, a right-only edit with the same torque change, and a double edit. The single edits produce equal and opposite net torques; the double edit changes both side torques while preserving zero net torque and the balanced outcome.

The custom scenes use the original renderer and bounded units/distances, but every geometry is absent from Dataset v1. Selection uses only the physics oracle and metadata. The experiment tests left/right task selectivity, signed net-torque transport, same-net invariance, an additive hidden-state factorial diagnostic, and terminal outcome use at the previously frozen Qwen-27B layers. It performs no layer, component, or head search.
