# VisualTorque — Qwen-27B Semantic Error Control and Code Mediation

This confirmatory audit freezes the Qwen-27B L49 physical-side response site
and L55 answer-code site discovered in the preceding depth profile. A semantic
direction library is built only from the locked 32-family remapping support;
all error tests use a separate, pre-existing 48-family shortcut-conflict
manifest. Counterbalanced prompts swap the A/B/C labels assigned to the exact
and shortcut sides. The experiment asks whether L49 can both rescue stable
shortcut errors and induce the matching error while remaining invariant to
the label swap, and whether the resulting downstream L55 change aligns with
the target prompt's correct output code. L55 code steering and equal-norm
random directions are mandatory controls. This notebook runs Qwen-27B only.
