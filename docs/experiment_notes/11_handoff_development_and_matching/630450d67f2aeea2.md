# VisualTorque — Qwen-27B Right-Side Error-Specific Handoff

The large behavior-only mirror screen found 14 pairs that Qwen-27B answered
correctly in both orientations and 69 pairs for which it answered the left
orientation correctly but the right orientation incorrectly.  A complete
side × correctness factorial is impossible because no stable left-error /
right-correct pair exists.  This notebook therefore runs the strongest
identified partial design.

All 14 both-correct mirror pairs are retained.  Fourteen left-correct /
right-error pairs are selected by a deterministic bipartite match on physical
cue type, torque margin, and orientation-neutral geometry.  The two cohorts
reuse the same frozen Qwen-27B revision, L48 route, L49 physical coordinate,
L55 response-code directions, answer mappings, and parent-calibrated dose.
No new layer, direction, dose, or example is selected from the causal results.

For every matched quadruplet the experiment estimates:

1. the right-minus-left intervention effect when both orientations are correct;
2. the right-minus-left effect when only the right orientation is wrong;
3. their difference, which asks whether a late asymmetry is specifically
   associated with the error rather than with rightward physical direction.

This is not presented as a complete 2×2 interaction.  It identifies the
right-side correct-versus-error contrast while using the left-correct scenes
and the both-correct mirror pairs as controls.
