# VisualTorque — Qwen-27B Net-Torque-to-Semantic Handoff Mediation

The preceding frozen rescue experiment found a sharp stagewise dissociation:
strengthening the L32 linear net-torque axis did not change any of 24 stable
errors, whereas a physically correct L49 left/right intervention produced a
large, directional, dose-dependent rescue.  That result identifies the
earliest tested sufficient site, but it does not yet show whether the upstream
failure is specific to the chosen L32 axis or whether a correct upstream
perturbation actually fails to reach the L49 physical-decision state.

This notebook tests that missing transition directly.  The same 24 targets are
split before any new intervention into an eight-scene route-discovery set and a
sixteen-scene confirmation set.  On discovery only, four predeclared layers
(24, 32, 40, 48) and two representations are compared: the frozen linear
readout axis and a four-component PLS prototype direction.  Every direction is
learned only from the previous `probe_train + probe_dev` outcome states.  The
single winning upstream route is then locked.

On the untouched confirmation scenes, the notebook measures two internal
transitions rather than only the final answer:

1. whether a correct upstream net-torque perturbation moves the L49 state in
   the correct physical left/right direction;
2. whether a correct L49 physical perturbation moves L55 toward the answer code
   required by the target prompt's current A/B/C mapping.

Both mappings, reversed-physics controls, stale-code controls, and equal-norm
random controls are mandatory.  A failure of every frozen upstream route to
move L49, together with successful L49-to-L55 transport, is direct evidence
for an operational net-torque-to-physical-semantic handoff fracture.  A
successful upstream route instead shows that the earlier L32 single-axis
intervention was underspecified.  Neither result assumes a globally serial or
one-dimensional computation.
