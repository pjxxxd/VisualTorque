# VisualTorque — Orientation-Specific Mediator Symmetry Reanalysis

The parent mediator-matching notebook correctly showed that the fixed L48
route creates nearly identical L49 physical-side movement for original-right
and mirrored-left scenes.  Its final label was nevertheless too strong because
downstream equivalence was tested only after averaging the two orientations.
Opposite orientation-specific discrepancies can cancel in that average.

This CPU-only notebook performs a corrective, explicitly post-hoc reanalysis
of the already frozen scene-level records.  It never loads Qwen and runs no new
intervention.  Equivalence of the L49 coordinate, L55 answer code, and answer
margin is tested separately for original and mirror scenes.  Side symmetry is
also tested with paired original-minus-mirror differences.  The analysis
explicitly records that orientation is perfectly confounded with baseline
behavior in this cohort: all original scenes were wrong and all mirrors were
correct.  Consequently, a downstream difference cannot be attributed uniquely
to physical side or to correctness state.

The corrected claim is deliberately narrow.  Symmetric L48-to-L49 transport
can be retained if it passes in both orientations.  L49 is called a sufficient
symmetric mediator only if L55 and answer equivalence pass separately in both
orientations.  Otherwise the result motivates a new balanced 2×2 experiment
crossing physical side with baseline correctness.
