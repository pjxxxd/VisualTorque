# VisualTorque — Qwen-27B Competence-Matched Clearance Readiness

The previous graded composition test could not be interpreted as a clean
mechanism test because Qwen-27B never answered both endpoints correctly when a
natural weight or distance change flipped the physical outcome.  This notebook
therefore performs the next, cheaper stage before any new activation
intervention: it constructs a large independent pool in which target scenes have
exactly matched initial net-torque deficits, screens natural target/hybrid image
pairs, and freezes a competence-conditioned confirmation manifest only when
enough answer-flip and no-flip contexts are solved correctly.

The behavioral criterion, target sample sizes, prompt, label counterbalancing,
prior-scene exclusions, and readiness gates are locked before model inference.
Behavior is allowed to determine eligibility because the eventual claim is
explicitly conditional on cases the model can solve; it never selects a layer,
token region, intervention direction, or effect size.  All screened cases remain
in the audit so the conditional analysis cannot conceal the unconditional
behavioral ceiling.
