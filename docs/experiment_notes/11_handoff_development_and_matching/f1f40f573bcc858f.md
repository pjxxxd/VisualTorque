# VisualTorque — Qwen-27B Matched Fracture Localization and Reciprocal Repair

The preceding expanded-support experiment established a sharp boundary: a reusable weight-change signal can modestly move answers, but the strength of the previously frozen route does not explain which presentation of the same physical transition is solved correctly. This notebook asks where the successful and failed computations first become causally distinguishable.

Every unit is drawn from a previously frozen outcome-flip bundle. A reference presentation solves both the pre-edit and post-edit scene; its matched target presentation solves the pre-edit scene but fails after the weight change. The pair may differ in exactly one presentation factor—mirror orientation or answer-letter mapping—and the correct output letters must differ. Therefore, a repair cannot be explained by copying the reference answer.

For each pair, the notebook captures the within-presentation base-to-edited activation change at five preregistered stages: L48 factor update, L49 physical handoff, L55 response-code formation, L57 late route, and L63 readout. It then performs reciprocal tests: the successful change is placed into the failed target, and the failed change is placed into the successful reference. Norm-matched random, reversed, self-update, and donor-letter-copy controls are included.

Stage choice is made only on a family-disjoint discovery split. The chosen stage for each edge type is then tested once on untouched confirmation families. Cohort selection uses behavior only and never uses intervention outcomes.

Run top to bottom in a fresh Colab GPU session. Endpoint replay and intervention shards are resumable under a new result directory.

## Stagewise reciprocal transport

The target base is a correctly solved starting point. At each stage, the notebook compares the target's own failed base-to-edit change with the successful change from its matched reference, a norm-matched random change, and a reversed reference change. The reverse direction places the failed target change into the successful reference. Discovery and confirmation families remain disjoint.
