# VisualTorque — Qwen-27B Correct-Source Distance-Error Rescue

The preceding matched-clearance experiment found an informative asymmetry.
Amplifying a failed pair's own weight-change state rescued some weight errors,
whereas amplifying a failed pair's own distance-change state rescued none.  Yet
subtracting the distance-change state from three correctly solved pairs reliably
induced the expected error.  This notebook asks whether failed distance cases
lack a usable distance update rather than merely expressing it too weakly.

For every independently frozen distance failed-update pair, the notebook finds
a scene-disjoint source pair in which the same distance change occurs on the
same side, the weight context differs, both endpoints are answered correctly,
and the physical answer does not change.  The source therefore supplies a
successful distance update without supplying the desired answer.  Its L48
option-token state difference is norm-matched and added to the failed hybrid.
The primary comparison is against the failed pair's own update, an answer-neutral
weight-change update, and an equal-norm random direction.  The previously frozen
L49 option-token and L57 final-token route is then restored to determine whether
any rescue is carried through the established response pathway.

All target and source eligibility is determined from behavior before activation
capture.  Source scenes are disjoint from every preceding rescue/induction scene,
all selected scenes are unique, and no activation result may select a pair,
layer, token region, direction strength, or statistical endpoint.
