# VisualTorque — Qwen-27B Mediator-Matched Handoff Symmetry

The previous split-sample experiment found that an L48 four-component PLS
state reliably moved L49, L55, and the answer in the physically correct
direction, but with only about one quarter of the downstream effect produced
by a direct L49 intervention.  This notebook tests whether that pattern is a
true, symmetric attenuation through L49 or merely a right-answer-specific
association.

The L48 route is fixed from the completed parent experiment.  Its intervention
strength is calibrated once from the parent confirmation results so that the
expected L49 movement equals one standard direct L49 physical-side
intervention.  No result in this notebook changes that route or strength.
Sixteen parent confirmation scenes are paired with horizontally mirrored
images whose correct physical side is reversed.  Both A/B/C mappings are used
for every original and mirror; mirror competence is reported but never used to
select scenes.

The central comparison holds the measured L49 physical coordinate constant:

1. create it indirectly by strengthening the frozen L48 PLS route;
2. create the same coordinate directly at L49;
3. compare the resulting L55 answer-code state and final answer.

If matched L49 states produce equivalent downstream effects on both physical
sides, L49 is a sufficient measured mediator of this route.  If the L49
projection matches but L55 or the answer differs, the one-dimensional L49
coordinate is incomplete: additional state components travel with the direct
L49 intervention.  Failure on mirrors instead bounds the prior result as
right-side-specific.  These are deliberately narrower claims than a globally
serial computation.
