# VisualTorque — Right-Side Common-Support Matching Readiness

The first right-side error-specific intervention produced a strong late-state
signal, but the both-correct and right-error cohorts differed substantially in
their physical configurations.  This notebook asks a narrower question before
any additional model run: does the existing Dataset v1 behavior screen contain
a sufficiently large region in which those cohorts can be compared at similar
weight, distance, torque, and cue structure?

The analysis uses all 14 left-correct/right-correct mirror pairs and all 69
left-correct/right-error pairs from the frozen behavior-only readiness screen.
It never reads hidden states, intervention results, or causal effect sizes.
Candidate matches must share the same cue-conflict category and lie within one
absolute-net-torque bin.  A binary optimization then maximizes cohort size
while constraining differences in standardized physical feature means.

Readiness requires at least eight unique matches, exact cue-category balance,
the torque-bin caliper, and a post-optimization maximum absolute standardized
mean difference no larger than 0.5.  Ten matches are the preferred target.  If
the gate fails, the notebook identifies which physical dimensions lack common
support so that new scenes can be generated deliberately rather than adding
undirected volume.
