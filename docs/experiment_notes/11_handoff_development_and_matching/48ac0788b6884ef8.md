# VisualTorque — Qwen-27B Matched-Clearance Flip-Error Rescue and Induction

The readiness screen showed a specific failure mode: natural weight or distance
changes often moved answer probabilities in the correct direction, but Qwen-27B
rarely changed the final answer when the physical outcome flipped.  This notebook
tests whether that error is causally connected to the corresponding internal
factor change.

For every model-blind matched-clearance target/hybrid pair, the natural L48
state difference at option tokens is treated as the factor-change direction.
On failed-update errors (target correct, flipped hybrid wrong), the notebook adds
0.5x, 1x, and 2x of that direction to the hybrid state and tests targeted rescue.
On the smaller set of correctly solved flips, it subtracts the same graded
direction and tests error induction.  At every strength, the previously frozen
L49 option-token and L57 final-token route is restored to clean, with an
equal-norm random restoration as control.

Behavior chooses only the predeclared error/control cohorts.  It never selects
an activation layer, token region, direction strength, route, or outcome metric.
All inference is resumable and clustered by independent image pair.
