# VisualTorque — Qwen-27B Distributed Factor-Mediator Subspace

The preceding decision-neutral recombination experiment showed a reliable
answer-level interaction for weight and a weaker but consistent interaction
for distance.  However, removing the previously discovered one-dimensional
L49 physical-side axis did not attenuate either effect.  That result rules out
one specific serial account; it does not show that the interaction has no
internal mediator.

This notebook asks the next falsifiable question: **is the factor-context
interaction carried by a low-dimensional, distributed response subspace at
L49–L55?**  It uses only the four upstream pilot families per factor to choose
the layer and dimensionality.  The selected basis, layer, dimension, gates,
and analysis are then frozen before evaluating the 20 held-out confirmation
families per factor.  The confirmation intervention removes only the factor-
induced component inside that basis.

The main controls are (i) an equal-norm random subspace removal, (ii) the old
one-dimensional L49 axis, (iii) self replay, (iv) a natural hybrid image, and
(v) the established L49 semantic oracle.  A positive conclusion requires a
background-appropriate factor effect, selective attenuation by the frozen
subspace, and replication in both target backgrounds.  This is a mechanism
follow-up on an existing support; the confirmation split is held out from the
present fit but is not globally unseen because it was used in the preceding
experiment.
