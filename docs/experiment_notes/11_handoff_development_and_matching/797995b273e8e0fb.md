# VisualTorque — Qwen-27B Error-Conditioned Physical-State Audit

This notebook begins the paper's stage-by-stage *fracture* analysis on one
common set of examples.  It asks a deliberately narrower question than the
earlier intervention notebooks: when Qwen-27B gives the wrong outcome, which
physical quantities were still available, and which functional transition is
the first one that fails?

The full bounded single-stack grid in Dataset v1 is used: all 900 distinct
weight-distance configurations are scored once with a counterbalanced outcome
prompt.  Linear readouts are trained only on `probe_train`, their layer and
regularization are selected only on `probe_dev`, and `probe_test` is opened
only after those choices are locked.  Within `probe_test`, every stable outcome
error is paired with a behaviorally correct scene of similar physical
difficulty.  The same scenes are then asked for left/right weight, distance,
side torque, and net torque.

The result is an error-conditioned map of four observable transitions:

1. read and bind weight/distance to the correct side;
2. combine each side's factors into side torque;
3. aggregate the two side torques into net torque;
4. use net torque to choose the final outcome.

This notebook does **not** claim that a probe proves a pure or uniquely causal
representation.  It freezes independent candidate cohorts for the next
stagewise intervention notebook.  A causal fracture will only be claimed when
an upstream state is supported here and a later, targeted intervention repairs
or induces the predicted behavior.
