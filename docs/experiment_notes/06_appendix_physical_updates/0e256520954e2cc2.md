# VisualTorque：Native 物理更新的对齐／残余分量与交互（96 GB v1）

**问题：上一轮的答案分数收益来自哪部分更新？为什么方向对齐，却没有整体接近自然反事实状态？**

本轮保留已审计的 **24 个家族、2 个镜像、6 个接收答案映射、2 个来源背景 × 2 个来源映射**。使用原 Native GPU `review_bundle.zip` 恢复图片、提示和家族，重新捕获本轮自己的 BF16 状态。旧文件只读，结果写入新目录。无需旧大张量缓存；不是再次扫描层、重新筛家族或运行 LoRA。

### 分解与固定干预

L48 最终提示 token（0-based）上的来源重量更新记为 `v`，仍使用父实验的相对范数缩放。接收端真实 before→after 状态差记为 `g`：

`A = <v,g>/<g,g> × g`，`R = v − A`。

这里 **A 是相对于本输入自然反事实位移的投影，R 只与这一条轴正交**。R 可能含有有用信息，不能提前命名为噪声；g 也可能混合视觉、上下文与答案相关变化，不能叫纯物理轴。投影系数保留正负，不取绝对值、不截断。零自然位移时明确记录退化轴，A=0、R=v，不删样本。

| 条件 | 目的 |
|---|---|
| 0、A、R、A+R=v | 固定 2×2 分量干预，测量分量作用及非加性交互 |
| 0.5v、A+0.5R | 区分整体减量与只减少残余分量 |
| 两个 `random_A` | 与 A 等范数、随机取向的对照 |
| 两个 `A+random_R` | 保持 A 和 R 范数，将 R 在 g 的正交空间内随机旋转 |
| 0.5g、g（每个接收输入共享） | 使用目标反事实状态的局部位移参照 |

每输入 **39 个条件**，共 **22,464 次干预 + 1,536 次自然端点评分**，同时测量 L48/L49/L55。默认 96 GB GPU、BF16、batch=1、与父实验相同的模型 revision 和软件版本。运行中显示 ETA；按每个条件落盘，重启后 Run all 续跑。

### 研究定位与冻结检验

**这是已有队列上的、使用目标反事实状态的机制诊断，不是新独立复现，也不是不看目标的可部署迁移方法。** 分解规则和六项检验在新干预前固定，但实验问题来自上一轮结果，不能把同队列分析描述成盲测新数据。L48 上 A 的对齐、R 的正交以及移除 R 后欧氏距离不增加，均由分解方式保证；不能当作新实验证据。真正的检验在输出和 L49/L55。未经分解的 full 仍不使用目标 after 状态；A、R 和相应组合均使用它。

flip 场景的六项双侧家族符号翻转检验统一 Holm 校正：A−0、R−0、full−A、A−平均 random_A、full−平均(A+random_R)、full−A−R+0。报告正／负方向，不以“必须阳性”作为成功标准。镜像、映射、来源和随机种子先在家族内平均，统计单位始终是 24 个家族。区间是逐项家族 bootstrap 95% CI，不是同时置信区间；符号翻转推断依赖零假设下家族差值的对称性。

同时报告 full 在本轮与父实验的分数重放差、三分类准确率、stable 保留变化、逐家族／映射边界、来源预测稳定子集、L49/L55 方向与真实距离。A 与 full 范数不同，所以单凭 full−A 不能把差异归因于残余“内容”；须结合等范数旋转对照。所有匹配首先在未量化向量上成立，实际 BF16 位移的范数、投影及分量加和误差另行审计。行为交互也不能自动归因于神经网络非线性，BF16 舍入可能贡献其中一部分。

`g` 参照采用与其他条件相同的 BF16 加法，不是强制精确替换。仅改 L48 最终 token，其他 token 和早期状态仍来自 before 图片，因此不保证重现整张 after 图片的预测。它也不是准确率的理论上界。
