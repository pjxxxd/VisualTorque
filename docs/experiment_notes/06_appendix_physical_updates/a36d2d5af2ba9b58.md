本轮要把论文结论收敛到数据真正支持的范围：

1. 从原始 clean / intervention JSON 重建 22,464 条干预和 67,392 条状态测量，核对原六项主检验与准确率表。
2. A 的作用覆盖多少家族？逐一删除家族、拆分接收映射、镜像、来源背景／映射时怎样？
3. **直接配对比较 A 与 full 的准确率差**，区分修复和退化。包括 A+0.5R、0.5v、g/2 与 g 的次级对照，不把“各自相对 clean 不显著”当作相等。
4. BF16 之后等范数是否仍近似成立？固定报告 **1%、2%、5%** 的配对最大范数误差限制；同一配对的两个随机种子必须同时满足。联合限制 A 与 R 控制；同时单独展示范数匹配、量化加和误差、A 幅度和零有效位移。
5. 在完全相同的配对上比较输出变化与 L49/L55 距离变化，列出“分数改善／距离改善”的联合覆盖，不用相关性冒充中介。

**这是看过结果后的 CPU 次级审计，没有新增确认性 p 值或通过门槛。** 原六项检验严格沿用原 seed、家族 bootstrap、符号翻转和六项 Holm 校正。新增区间均为逐项描述性家族 bootstrap；所有筛选规则在本次读取干预结果前固定，所有档位都输出，包括阴性、空集和低支持结果。镜像、答案映射、来源变体及随机种子均不是独立样本。

阈值只筛选干预前已经算好的几何／量化记录，不按干预收益筛样本。原全体结果始终保留。筛选后按支持家族等权平均，并报告完整支持数、同一支持家族的未筛选结果、逐家族保留比例；子集不能重新包装成新确认数据。阈值敏感性不等于纠正、重加权或模拟一次新的精确等范数实验。

A 沿目标自然反事实位移，R 只对这条一维轴正交；A/R 不是已识别的纯物理／噪声坐标。L48 的几何性质来自构造，L49/L55 及输出才是实测效应。BF16 注入加和本身存在舍入差，因此行为交互不是纯网络非线性证据。

**包内没有完整隐藏张量。** 本轮核对标量重建、文件身份、逐条已保存的向量核验摘要；不能重新进行逐元素隐藏向量核验。两随机种子的范数误差使用 FP64 有效范数重算；不依赖 pandas 自动 `_saved` 后缀或跨设备 FP32 范数的极小绝对阈值。
