# VisualTorque — Qwen3.5-35B-A3B BF16 Fracture Replication

This notebook tests the paper's physical-information-fracture story in the official, non-quantized Qwen3.5-35B-A3B BF16 checkpoint. It uses exactly the same 900 single-stack scenes, deterministic answer mappings, and train/dev/test split as the frozen Qwen-27B experiment, so the model comparison is paired scene by scene and has no quantization confound.

The experiment first asks whether this checkpoint is actually more competent on VisualTorque. It then learns 35B-specific linear readouts for weight, distance, side torque, and net torque using train/dev scenes only; freezes outcome errors and matched correct controls using behavior alone; and maps which physical quantities remain available when the final answer is wrong. The result authorizes a later causal rescue experiment only when a prespecified fracture class has enough independent errors.

Qwen3.5-35B-A3B is a sparse mixture-of-experts model with 35B total and about 3B active parameters, so this is a larger-total-parameter, cross-architecture replication rather than a pure dense scaling law. Run in a fresh session on one CUDA GPU with at least 90 GiB of memory. Scoring is batch-one, outputs are sharded, and interrupted runs resume safely.
