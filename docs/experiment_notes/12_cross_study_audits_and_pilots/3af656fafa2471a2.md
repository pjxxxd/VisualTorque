# VisualTorque — Mechanism-to-Error Prediction Audit

This CPU-only confirmatory analysis asks whether the frozen causal mechanism measurements have predictive value beyond ordinary behavior. It uses all 80 Qwen3.5-27B phase-map families and never filters on correctness.

The primary target is same-net counterfactual instability: whether replacing a scene with a different scene that preserves signed net torque and the correct answer nevertheless changes the model's prediction. Four frozen predictors are compared with repeated family-grouped cross-fitting: scene metadata, metadata plus clean confidence, confidence plus mechanism features from the wrong task, and confidence plus task-matched mechanism features. The primary claim requires matched mechanism features to improve held-out log loss and Brier score over both controls, survive family-level inference, and retain a positive advantage when an entire cue-congruence × torque-margin cell is held out. Base and mirror errors are secondary targets.
