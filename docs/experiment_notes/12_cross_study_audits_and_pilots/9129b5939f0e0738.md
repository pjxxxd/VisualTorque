# VisualTorque — TorqueTangent natural-mediation pilot on one A100

The earlier experiments established a sharp gap: signed net torque is linearly
decodable, but adding the probe direction to the final prompt token did not reliably
improve the answer. This notebook tests the next question without editing any
activation value:

> When a real, nuisance-matched image perturbation changes torque, does the model's
> naturally induced hidden-state motion along the frozen torque-probe direction carry
> the answer-margin change?

For a held-out center scene, only one stack's horizontal position is changed by a small
symmetric amount. The renderer, prompt, blocks, colors, camera, crop, option order, and
all non-target geometry remain fixed. At the frozen decoder layer we estimate

\[
\dot h=\frac{h(\tau+\epsilon)-h(\tau-\epsilon)}{\Delta\tau},\qquad
d=\frac{m(\tau+\epsilon)-m(\tau-\epsilon)}{\Delta\tau},
\]

and obtain \(g=\nabla_hm\) from the unchanged center forward pass. The chain-rule
reconstruction \(g^\top\dot h\) is a mandatory validity check. Only if that check and
epsilon stability pass do we interpret the probe-aligned response
\(r=g^\top P_\beta\dot h\) and its held-out mediation coefficient

\[
U=\frac{\sum_i r_i d_i}{\sum_i d_i^2}.
\]

This is a **feasibility pilot**, not a new confirmatory result. It defaults to 40 Qwen
probe-test centers and is designed for a Colab A100 40 GB. It is append-only and
resumable. If the gates pass, run Gemma in a fresh runtime and then freeze a scaled
protocol. If they fail, do not interpret \(U\).

## 2. Build held-out continuous torque paths

Each center comes from `probe_test`. We extend the original deterministic renderer only
by allowing the target stack distance to be fractional. The center render must be
pixel-identical to Dataset v1. This gives a local physical path without reusing a
probe-training image as an endpoint.

## 3. Exact cut-gradient and tangent contractions

The center hook replaces the block output with an equal-valued detached leaf only to
stop backpropagation below the selected layer. No numerical activation value is changed;
all downstream operations are the original model. This computes the exact local gradient
of the answer margin with respect to that block output while fitting in 40 GB.

## 原单元格 16

## 4. Validity gates before mediation

The mediation number is not self-validating. First, the all-token tangent must reconstruct
the observed answer derivative, and the estimate should be stable when epsilon is halved.
These thresholds are pilot diagnostics; if they fail, revise the path resolution or margin
before scaling rather than interpreting a null.
