# VisualTorque — Fidelity/Error Alignment Reanalysis

This notebook performs a **CPU-only, post-hoc reanalysis** of the completed Qwen-9B, Gemma-12B, and Qwen-27B stress-prediction experiment. It never reloads a model and never regenerates an image.

The pre-registered question—whether one scalar causal-fidelity score improves prediction of generic correctness beyond ordinary behavior—was not confirmed. That decision remains frozen. This notebook does three narrower things:

1. corrects the state-metadata deduplication bug in the paper-facing robustness table (48 states, not 12);
2. asks whether each task-matched route is aligned with the **specific predeclared shortcut answer** rather than with every possible error;
3. measures whether four calibration families are sufficient to estimate a stable route score, and compares causal equal-net invariance with behavioral equal-net stability.

These analyses are exploratory. A positive result can motivate a new independent confirmation set; it cannot retroactively rescue the failed primary claim.
