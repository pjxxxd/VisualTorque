# VisualTorque — Path-Integrated TorqueTangent v2 on one A100

The first TorqueTangent pilot produced a useful methodological null: behavior changed,
but one center gradient did not reconstruct the finite endpoint change, and halving the
displacement changed the hidden tangent direction. Therefore its mediation coefficient
was not interpretable.

This notebook replaces that estimator with a path integral over **17 unmodified model
runs per scene**. A target stack is translated smoothly over only ±4 screen pixels while
the beam, ticks, blocks, colors, camera, prompt, and option mapping remain fixed. At every
path point it records the selected-layer state \(h_j\), answer margin \(m_j\), and exact
cut-gradient \(g_j=\nabla_{h_j}m_j\). For each adjacent natural path segment,

\[
\Delta m_j\approx
\frac{g_j+g_{j+1}}{2}^{\!\top}(h_{j+1}-h_j).
\]

Summing the 16 segments gives a 17-point path-integral reconstruction. The identical
calculation on every other point gives an independent 9-point approximation. Agreement
with the observed endpoint margin change and convergence from 9 to 17 points are hard
validity gates.

Only after those gates pass do we decompose each natural segment into the frozen
scene-level torque-probe component at the final prompt token, the remaining final-token
component, and all other tokens. No model weight or activation value is changed.

This remains a **12-scene Qwen feasibility pilot** for an A100 40 GB. Do not switch to
Gemma or scale the sample until the final decision cell says the estimator is validated.

## 2. Construct smooth, held-out, pixel-local torque paths

Each center is a unique `probe_test` single-stack scene. The renderer separates the
target stack from the static scene, translates only that layer, and composites it back.
At zero offset the result must be pixel-identical to Dataset v1. Positive path coordinate
always means increasing signed torque, regardless of which side is moved.

## 3. Natural-path gradients and segment-wise line integration

The hook substitutes an equal-valued detached leaf only to cut backward memory below the
selected layer. It does not numerically edit the activation. Fine integration uses all 17
points; coarse integration uses the 9 even-indexed points from the same path.

## 原单元格 16

## 4. Validate the estimator before interpreting the probe

The primary gate compares the 17-point all-token integral with the observed endpoint
answer change. The convergence gate compares the 9- and 17-point estimates. We also
require a nontrivial behavioral response and verify that the frozen global probe moves
in the physical torque direction on most held-out paths.
