# VisualTorque — Qwen-27B Within-Context Weight-Route Gating Audit

The previous audit found that confidence across different physical families was
associated with stronger downstream route attenuation and specificity, but it
did not predict the total weight effect on unseen families. That association
could still be a difficulty confound: easy physical scenes may be both easier
to answer and easier to analyze internally.

This notebook removes that confound by comparing only the four paired cells of
the same physical family and target context: left/right mirror crossed with
forward/reverse answer mapping. Every outcome and competence measure is centered
within that four-cell bundle before testing. The question is therefore:

> For the same underlying weight change, is the identified downstream route
> stronger in the particular orientation or answer mapping where the untouched
> model handles both endpoints more confidently?

Route specificity is the primary outcome because this is a focused follow-up on
the downstream route association. Route attenuation is confirmatory secondary;
the total shared-over-random output effect is retained as a boundary control.
Edits that change the correct outcome are analyzed separately from edits that
preserve it. Complete physical families are the uncertainty and held-out unit.

This is an analysis-only follow-up. It does not load model weights, select cases
by intervention success, or turn an association into a causal claim.
