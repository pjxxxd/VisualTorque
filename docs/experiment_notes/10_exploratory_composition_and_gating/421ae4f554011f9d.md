# VisualTorque — Cross-Context Composition Paper Robustness Audit

This notebook audits the completed Qwen-27B cross-context factor-composition
experiment without loading the model or running new interventions. The family,
not the target image or intervention record, remains the independent unit.

The audit asks whether the weight result survives removal of any one family,
appears in both answer mappings and both physical sides, and remains positive
after excluding every family that reuses a scene from the earlier graded
composition experiment. It applies the same checks to distance so that a weak
overall result cannot hide a stable subgroup effect. These are robustness and
scope checks; they do not redefine the frozen confirmatory decision.

This notebook can run on a CPU Colab runtime. It writes only to a new
'paper_robustness_audit' subdirectory of the completed result folder.
