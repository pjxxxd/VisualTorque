# VisualTorque — Qwen-27B Outcome-Flip Within-Context Route-Gating Confirmation

The previous within-context audit found that endpoint confidence tracked the
specificity of the frozen L49/L57 route, but the supported association was
concentrated among weight edits that preserved the final answer. This notebook
performs a new A100 confirmation using only edits where the correct outcome
changes after the weight intervention.

Every selected physical target is evaluated under an exact left-right mirror
and forward/reverse A/B/C mappings. Families used in the previous factorial
confirmation are excluded. Cohort selection uses only exact physics and
untouched clean/natural outputs; no intervention output is available during
selection. The L48 upstream site, L49 options-token route, L57 final-prompt
route, equal-norm random controls, batch policy, and estimands remain frozen.

The primary question is whether, within the same outcome-flipping physical
bundle, greater untouched confidence in both endpoints predicts greater route
specificity. Route attenuation is confirmatory; the total shared weight effect
is a boundary measure. Complete physical families are bootstrapped and held out.
