# VisualTorque — Qwen-27B Expanded Cross-Context Source Readiness

The first correct-source distance-rescue pilot was technically valid but could
freeze only three independent target/source bundles.  The bottleneck came from
reusing the narrow matched-clearance family pool: it contained only nine
answer-neutral distance sources and six weight controls.  This notebook performs
the required behavior-only expansion before any further activation experiment.

The failed-update target definition is unchanged.  Source candidates are now
enumerated directly from all 900 single-stack Dataset-v1 scenes.  A distance
source must implement the exact same distance change on the same side, preserve
its answer, use a different weight context, and have a source answer different
from the target's desired answer.  A weight control must preserve its answer and
match the target's physical dose as closely as possible.  Every endpoint is
rescored one example at a time under the target's exact A/B/C mapping.

No activation is captured.  The next confirmatory intervention is authorized
only if the frozen manifest contains enough scene-disjoint bundles with both
label mappings, both changed sides, exact distance geometry, acceptable weight
control matching, and zero behavior violations.
