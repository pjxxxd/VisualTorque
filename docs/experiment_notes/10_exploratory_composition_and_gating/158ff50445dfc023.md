# VisualTorque — Cross-Context Factor Recombination

This notebook tests whether a weight or distance change is a transportable internal factor rather than a copy of the donor scene's completed torque. It builds model-blind 3×3 weight–distance grids, applies the same contrastive factor delta to two held-out target backgrounds, and asks whether the model favors the new hybrid torque.
