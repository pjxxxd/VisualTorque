# VisualTorque — Qwen-27B Symmetric L55 Code-Axis Test

The preceding post-hoc audit found a pair-specific directed cycle among the
six A/B/C transitions. This prospective A100 follow-up distinguishes an
estimation artifact from a model-level code asymmetry. The 32 direction
families are stratified into calibration and confirmation halves. Calibration
constructs both six independently directed code vectors and three sign-
symmetric pair axes; confirmation tests their held-out geometry. The target
experiment uses the 43 families assigned to the same stable cohort in both
completed runs and evaluates every one of the six label permutations.

For each permutation, the notebook compares the total L49 effect, removal of
the original directed component, removal of the symmetric pair-axis
component, an equal-magnitude random removal, and raw/symmetric component-only
states. All direction tensors are saved. This notebook runs Qwen-27B only.
