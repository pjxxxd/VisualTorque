# VisualTorque — Qwen-27B Response-Subspace Dimension Saturation and Cross-Alphabet Transfer

The preceding experiment established that the L55 response interface is not
well described by one direction: all nine alphabet-by-code-pair cells selected
the largest tested dimension (d8), and removing that subspace blocked far more
L49-to-answer transport than removing d1 or a matched random subspace. Two
questions remain. First, d8 was the candidate ceiling, so the intrinsic scale
of the response interface is unresolved. Second, each alphabet was fit
separately, so the result does not distinguish a shared response core from
three unrelated alphabet-specific codes.

This frozen follow-up reuses the already captured 32 direction families and
expands the candidate dimensions to 1, 2, 4, 8, 12, 16, 24, and 32. Dimensions
are selected on the original calibration/confirmation split without consulting
the 24 causal target families. For each target alphabet, the notebook also
fits an alphabet-excluded basis using only the other two alphabets. On held-out
target scenes it compares removal of the target alphabet's own basis, the
alphabet-excluded basis, and separately norm-matched random bases.

The experiment can support a predominantly shared response interface, a shared
core plus alphabet-specific residual, codebook-specific interfaces, or mixed
transfer. It concerns downstream response coding between L49 and L55; it does
not establish how torque is computed upstream.
