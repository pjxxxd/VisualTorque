These families were previously observed at the unit dose, so this is a prospective dose test on reused support rather than a new-cohort replication.

The decisive control is target-code-only steering. A high-dose answer flip is evidence for a physical handoff only if the recoded physical residual adds value beyond directly pushing the target A/B/C response code.
