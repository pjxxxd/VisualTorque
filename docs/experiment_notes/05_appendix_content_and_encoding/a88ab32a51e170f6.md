# VisualTorque — Qwen-27B Response-Code Alphabet Replication

The preceding factorial showed that the asymmetric L55 mediation cycle
follows A/B/C token identity rather than option-line position. This
confirmatory follow-up asks whether that cycle is specific to the familiar
multiple-choice alphabet or recurs when the same physical semantics are
encoded with **X/Y/Z** and **1/2/3**.

Each codebook receives its own independently calibrated L55 pair axes.
Calibration and confirmation scenes are disjoint. The target analysis uses
42 frozen stable shortcut families, split into 18 discovery and 24 held-out
confirmation families. Within each split, a six-phase counterbalance makes
every ordered code transition cross every ordered option-position transition
equally often. The primary outcomes distinguish: (i) the same ordinal cycle,
(ii) a reversed but stable codebook-specific cycle, and (iii) disappearance
of the cycle outside A/B/C.

This experiment localizes the semantic-to-response interface. It does not
test whether the upstream torque calculation itself changes with answer codes.
