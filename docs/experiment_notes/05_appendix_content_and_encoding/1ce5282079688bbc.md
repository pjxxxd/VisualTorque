# VisualTorque — Qwen-27B Cross-Context Response-Code Subspaces

The alphabet replication found a stable L49 physical-result direction and
causal L55 response components across A/B/C, X/Y/Z, and 1/2/3, but most
independently estimated one-dimensional L55 pair axes did not reproduce.
This frozen follow-up tests whether the apparent instability reflects a
genuinely absent response representation or a response representation that
is multi-dimensional across prompt contexts.

For every codebook and every unordered code pair, all 32 direction families
now contribute two counterbalanced option orders and both transition
directions. Sixteen physical families estimate 1-, 2-, 4-, and 8-dimensional
subspaces; sixteen disjoint families select the smallest reproducible
dimension. The frozen subspace is then tested causally on the 24 held-out
target families from the preceding experiment. The primary comparison asks
whether removing the selected subspace blocks more L49-to-answer transport
than removing only its first direction, while a matched random subspace
controls for intervention dimensionality and norm.

L1–L2 is a preregistered positive control because its one-dimensional axis
reproduced across all three alphabets. This notebook concerns the downstream
response interface and does not establish an upstream torque-computation chain.
