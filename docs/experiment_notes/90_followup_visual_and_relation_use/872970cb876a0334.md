# 视觉信息支持：原提示与中性问法的独立验证

**现在直接运行本 notebook。默认 Gemma-12B 完成后，换全新 GPU 运行时，只改 `MODEL_KEY='qwen27b'`，再从头运行。**

固定 96 个新物理家族、240 个场景呈现；每个场景使用六种输入条件、三种 ABC 映射与两种固定问法。每模型 **8,640 次评分＋240 次短答案生成检查**。统计单位是物理家族，镜像、映射和交换伙伴不增加独立样本数。96 是固定预算规模，不是统计功效保证。

原问法保留全部原定比较；中性版本把 equal 改为 balanced (neither side tips)，并使用 What happens to the balance scale?。两项措辞变化在这里作为一个预设组合对照；不会根据验证正确率选择提示，也不会把两套结果混在一起。

五类家族：12 个一致方向、12 个真正平衡、24 个等重不同距离、24 个重量与力矩方向冲突、24 个重量—距离对应关系交换。两个模型共享全部输入。生成时排除记录在历史快照、开发、诊断及显式补充清单中的几何及其镜像；若旧 notebook 的 validation/support.json 已存在，也会排除其中场景。

需要原 Drive toolkit，以及两个开发输出 ZIP 和两个诊断输出 ZIP。默认按原目录读取四个文件，不递归扫描 Drive；移动过文件时填写 SOURCE_ZIPS。辅助代码全部内嵌，只需上传本文件。首次冻结后不改变来源清单、场景数量、种子、问法、评分方式或比较；中断可从头续跑。

使用上次成功的 GPU 环境，固定模型 revision、Transformers 5.14.0、Pillow 11.3.0、完整 BF16、batch=1 和关闭 thinking。Qwen-27B 沿用可容纳全量权重的 GPU（上次为 96 GB 级别）；不自动切换量化或 CPU 卸载。

新输出目录是 results/frozen_visual_validation_v1/main。原提示的七项比较每模型一套，跨模型共 14 项统一 Holm 校正；四项措辞比较每模型一套，共 8 项作为独立的次要检验族校正。中性问法下的信息支持效果另报配对区间，属于描述性结果。这两类检验族不构成一个全局 22 项错误率保证。

同时导出方向偏好、真平衡与误答平衡、镜像与交换双题全对、映射一致性及纠错／新增错误。完成两个模型后再看联合比较；不中途因为结果好坏增加样本或更换问法。这里测量固定直接回答协议下的行为，不测所有推理模式的能力上限，也不执行内部干预。
