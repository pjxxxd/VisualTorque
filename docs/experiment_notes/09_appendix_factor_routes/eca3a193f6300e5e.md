# VisualTorque — Context-Gated Weight Route and Depth Relocation

The previous equal-net experiment rejected two simple explanations of weight-shortcut errors. Weight-aligned internal states could repair some errors, but neither weakening nor strengthening a single factor produced a complete bidirectional error mechanism. This experiment tests the next, more conditional hypothesis: the weight-related route is gated by how the visual scene supports object binding, and its effective depth changes with model scale.

Each independent family contains one four-stack physical scene, a weight-neutral source, and a weight-aligned source. The sources keep all object positions, exact net torque, and correct answer unchanged. Every physical scene is rendered twice. The uniform rendering is the standard VisualTorque image. The grouped rendering adds identical, fixed-size neutral enclosures around all four stack locations; these enclosures do not encode weight, distance, side, torque, or answer. The physical scene and prompt remain identical across renderings.

The same source scene is therefore used in both visual contexts. Within every family, layer, and intervention direction, activation changes are norm matched across contexts and compared with context-specific random directions. The primary tests are prospective: Qwen 9B should express the route more strongly at its previously discovered middle factor site, whereas Qwen 27B should express it more strongly at its previously discovered late answer site. A paired context interaction tests whether binding support changes the route rather than merely changing behavior.
