# VisualTorque — Competence–Mechanism Robustness Audit

The grouped-route confirmation completed 192 pairs and 6,912 interventions.
Its frozen primary cohort (pre-existing outcome-both-correct) did not show
multiplicity-corrected physical-value specificity, but the pre-specified
custom-query-both-correct subset showed positive layer-16 effects while
unsuccessful computations did not.

This is a **post-confirmatory robustness audit**, not an independent
confirmation. It asks whether the competence-conditioned signal survives:

1. an explicit success × donor-value interaction blocked by edit and task;
2. a directional source-answer margin that avoids recovery normalization;
3. deterministic success/error matching on edit, task family, value gap, and
   natural-effect magnitude;
4. winsorization and natural-effect threshold sensitivity;
5. edit/task stratification and leave-one-edit-out analysis.

No model is loaded and no new intervention is run. The result determines the
design of the next independent GPU experiment; it cannot retroactively turn a
secondary finding into a confirmatory result.
