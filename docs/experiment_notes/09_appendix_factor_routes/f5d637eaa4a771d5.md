# VisualTorque — Orthogonal Value-Binding Control

This confirmatory control distinguishes factor-specific causal routing from generic scalar matching. Each locked triplet contains one base scene, one weight-edited scene, and one distance-edited scene. The two edits produce the same side torque, net torque, and outcome, but use unequal edit magnitudes and four non-overlapping scalar values:

\[
w_1 d_0 = w_0 d_1,\qquad |w_1-w_0| \ne |d_1-d_0|,\qquad
\{w_0,w_1\}\cap\{d_0,d_1\}=\varnothing.
\]

Run the notebook twice without changing the manifest: first with `MODEL_KEY = 'qwen'`, then with `MODEL_KEY = 'gemma'` in a fresh A100 runtime. The final cell performs the exact-pair cross-model comparison after both runs are complete. Captures are sharded by triplet and safely resume after interruption.
