# VisualTorque — Qwen-27B Depth Relocalization Audit

This audit asks one question left open by the frozen 9B→27B comparison: did the 27B torque route genuinely weaken, or did it move to a different decoder depth?

The exact 48 orthogonal triplets are deterministically split using scene metadata only. Twenty-four discovery triplets select one candidate depth for factor binding, torque-text routing, torque-option routing, and late-answer use from a fixed eight-layer grid. All causal claims are then tested once on the untouched 24-triplet confirmation split. Prompts, donors, answer scoring, equivalence bounds, and the pinned Qwen3.5-27B revision remain unchanged.

The notebook runs on one A100 80GB, saves one triplet per shard, and resumes safely after interruption.
