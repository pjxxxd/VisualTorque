# VisualTorque — Same-Manifest Factorial Composition

This confirmatory A100 notebook tests whether a VLM keeps weight and distance
information distinct and then transports their shared torque consequence. Each
analysis unit uses one base scene and two natural counterfactual sources: a
weight edit and a distance edit on the same side that produce exactly the same
side torque, net torque, and outcome.

Run the notebook twice in fresh runtimes by changing only `MODEL_KEY`: first
`qwen`, then `gemma`. Both runs read the same locked manifest. The final cell
automatically performs the exact-pair cross-model synthesis once both runs exist.
