## Reading the result

The main scientific distinction is between **physical-value specificity** and generic prompt sensitivity. A positive donor effect requires the same-value donor to outperform a donor that preserves the answer but changes the physical value. The formal cross-model contrast then asks whether that value-specific effect is larger in Qwen than Gemma after blocking edit and task family.

A failed Gemma replication supports only a statement about the prespecified mapped sites. It does not establish that Gemma lacks physical representations or physical understanding.
