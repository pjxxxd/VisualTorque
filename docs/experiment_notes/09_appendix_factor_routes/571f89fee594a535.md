# VisualTorque — Competence-Conditioned Grouped-Route Confirmation

The previous experiments established that torque is strongly decodable and that
counterfactual scene information follows an image → text → answer-boundary route.
The robustness audit did **not** establish that this route is specific to the
queried physical variable: 0/96 latent-relevance cells, 0/120 individual tokens,
and no matched-control component effect survived correction.

This notebook therefore performs a new confirmatory experiment instead of a head
search. It uses untouched counterfactual pairs, separates behaviorally successful
and error cohorts, and tests only six frozen grouped sites. Each task receives three
natural donors shared across both prompts:

1. the pair's matched source;
2. an unrelated scene with the **same source task value, unchanged-control
   value, and outcome**, but a different layout;
3. an unrelated scene with the **same source outcome and unchanged-control
   value but a different relevant-task value**.

The second-versus-third donor contrast asks whether a site transports the queried
physical value rather than a generic outcome state. The exact same two donor
scenes are patched under a relevant changed query and an unchanged control query.
Their output separation should be larger only when their differing physical value
is actually queried, giving a within-pair prompt-selectivity interaction.
Only if grouped physical-value specificity survives in successful computations may
layer-16 `linear_attn` be decomposed in a later notebook.

## 3. Pair-aligned task prompts and grouped token masks

Source, target, and both unrelated donors receive exactly the same pair-specific
prompt and A/B/C option mapping. Both prompts reuse the same donor scenes. The
donors are matched on the unchanged control value, while the relevant prompt
includes the outcome-only donor's relevant-task value as its third option.

## 4. Confirmatory analysis

The model is released before analysis. Recovery is the projection of the patched
semantic-logit change onto the matched natural source→target change. Statistical
tests resample or sign-flip counterfactual pairs, never individual patch rows.
