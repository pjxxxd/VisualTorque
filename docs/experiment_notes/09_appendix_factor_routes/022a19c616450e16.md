# VisualTorque — Inverse-Query Weight-Route Specificity

The previous independent experiment confirmed a strong late weight-aligned effect in Qwen 27B and a weaker but clearly middle-dominant effect in Qwen 9B. A remaining alternative explanation is that the late intervention transfers a generic answer-side state rather than weight information that is routed according to the question.

This experiment uses new equal-net base/source pairs and asks five questions about every identical image pair: the physical outcome, which side has more weight, which side has less weight, which side has greater total distance, and which side has smaller total distance. The source changes only weight while preserving all object positions, net torque, and the physical outcome. Consequently, the source value moves from the shortcut side to the exact-torque side for the “more weight” question, but moves in the opposite direction for the inverse “less weight” question. Both distance answers and the outcome remain physically unchanged.

A genuine query-routed weight state should therefore produce three signatures at the model-adaptive site: it should help the outcome question, transfer the weight value in opposite semantic directions under the two inverse weight queries, and produce little leakage into the two unchanged distance queries. A generic answer-side state cannot satisfy this sign reversal and factor specificity simultaneously. Qwen 9B and Qwen 27B are evaluated on the same frozen independent manifest at their prospectively selected middle and late sites.
