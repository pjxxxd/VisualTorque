## 这批实验固定了什么

**Qwen-27B 同幅度阻断。** 在原集合重新计算全部成对条件，增加三条路径各四个随机方向。匹配的是 BF16 写回后的实际移除量，容差为 2%；原随机坐标复位仍保留。默认共有 5,504 条干预记录，独立统计单位仍是 32 个匹配四元组。

**固定位置确认。** Gemma 固定 L37/L47，Qwen-9B 固定 L31，Qwen-27B 固定 L49/L63。三个模型使用同一 64 家族清单；五个位置的七项指标，加两个位置差异，共 37 项主检验，只有三模型完成后才统一校正。最后一个模型完成时自动汇总；已有结果可通过重新运行末尾汇总单元格重新整理。该实验检验固定位置的内容差异，不将两个位置解释成完整连续转换链。

**修正开发。** 新模型用原训练场景的六映射平均状态拟合 PLS4，开发集只比较六个预定上游位置、两个剂量和四个实际匹配随机方向。基准剂量定义为原训练隐藏状态范数中位数的 1%，实际比较其 0.5 倍和 1 倍。这是新模型明确采用的剂量适配，和 Qwen-27B 原先的中介匹配剂量不同。开发集选择依据是答案改善及其相对随机方向的优势；所有候选均保存。

**新家族修正—阻断。** 使用与固定位置确认不重叠的 64 家族，每家族四个镜像/渲染场景、两种映射。涵盖等重量看距离、重量与距离冲突、多物体求和、线索一致四类。最小路径是上游 U 到后续候选位置 B；不预设所有模型都有完整三阶段链。21 个条件包括随机上游、指定阻断、原随机坐标复位、同幅度随机移除和后端单独修正，默认每模型 10,752 条记录。先确认上游能改善答案，再判断其效果是否选择性依赖后续方向。

两组新家族均在采集前生成，排除已记录物理配置及其镜像。随机种子、映射和渲染变体先在家族内平均，不作为额外独立样本。默认样本量为 64；如需调整预算，应在首次生成和查看任何新输出前决定。
