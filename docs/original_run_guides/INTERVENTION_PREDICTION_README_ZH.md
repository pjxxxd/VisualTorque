## 这一轮要回答什么

我们已有一些干预能够改变答案，但它可能传递物理变化，也可能携带来源判断或输出字母。下一步检验：**这些解释能否在看见新场景的干预结果之前，预测候选答案的分数怎样变化，以及最终会选哪个答案？**

这与已有实验有明确区别。项目已经做过用机制指标预测自然错误的研究，未得到超过行为基线的增益；也做过跨背景重组和乘法规律检验，不能再把它们列为“尚未做过”。这一轮新增的是：固定具体干预操作，提前保存逐次干预预测，在未用于校准的物理家族上比较竞争解释。它不是另一轮泛化的“机制分数预测答错”。

## 两个实验模块

### A．同一个场景改答案映射，能否提前预测干预推动谁？

沿用等净力矩、重量判断相反的来源构造。来源问题分别询问“哪侧更重”和“哪侧更轻”；接收者一直回答倾斜方向。每个来源方向使用三种接收答案排列：

| 条件 | 用途 |
|---|---|
| 与来源相同的映射 | 给出解释相容时的参照 |
| 冲突排列一 | 让语义、字母、选项位置指向三个不同候选 |
| 冲突排列二 | 再交换剩余字母和语义，检验结果是否依赖某个排列 |

对每个指定干预，先预测三个候选的分数变化，再加到原始分数上预测干预后的选项。接收者的真值只用于最后判定修复、损害和未变化。

这里的相同映射条件也是**倾斜问题**，不同于一些旧实验中让来源问题自己接收干预的 identity control。因此这是面向答案预测的扩展，不能把整张表称为旧实验的逐项复现。

### B．同样增减一个方块，到底使用谁的距离？

每个家族独立交叉两个来源距离和两个接收距离。每张图有左右各两个堆叠；改变的始终是指定一侧**最靠近支点的堆叠**，该侧另一堆叠固定在距离 6。对应堆叠的初始重量在家族内相同，变化为增加或减少一个方块。

近距离取 1 或 2，远距离取 4 或 5。通过调整背景堆叠，使两个接收场景的原始净力矩相同；加上同样的重量变化后，近距离场景不改变物理结果，远距离场景改变物理结果。这里固定了原始净力矩，但背景图形与部分基本物理量会变化，因此不是“除距离外所有像素不变”的设计。

三种解释给出不同预测：

| 解释 | 预测依据 |
|---|---|
| 接收者使用了重量变化 | 重量变化 × 接收距离 |
| 携带来源的力矩变化 | 重量变化 × 来源距离 |
| 携带来源的答案偏好 | 来源候选分数或选中答案的变化，以及映射关系 |

来源图像修改前后的**真实倾斜方向**相同，但不强制模型的选项或置信度相同；后两者会完整记录，并单独报告来源选项未变的子集。

同样使用三种答案排列。来源距离、接收距离、答案排列都保留在结果表中，不能看完结果后只留下某个有利组合。

## 固定干预，而非给整层贴标签

| 模型 | 模块 A | 模块 B |
|---|---|---|
| Qwen3.5-27B | L49、L63 | L48、L63 |
| Gemma-4-12B-it | L37、L47 | L37、L47 |

层号从 0 开始，写入 decoder block 的输出，位置是评分前的最后一个提示 token；若候选评分器追加共同前缀，这个位置包含该前缀。它不是图像 token、选项 token，也不是生成出的答案 token。

两模块都使用原生 BF16 的来源末尾状态差，以固定系数 1 加到同层接收状态上；不扫描层、不根据接收者答案改符号、不重新搜索剂量。明确保存来源两个状态、差分、接收状态、实际改动大小、图像和提示的身份。

模块 B 是这里明确定义的**完整末尾状态差分**操作，不是已识别的纯重量方向，也不自动等价于项目中经过对齐、投影或残差化的其他 physical-update 操作。此前关于 L49 或 L63 内容的结论只能提供假设，不能替代本轮检验。Gemma 的物理模块同样是待检验扩展。

## 预测器和有竞争力的基线

每个模块、每个层单独校准。简单方向模型只拟合一个非负幅度；普通回归固定为 ridge，强度为 1，不搜索额外超参数。

- **不变基线**：预测干预完全不起作用。
- **置信度基线**：原始三个分数、分数差距、答案熵、实际计划改动大小、相对状态大小。
- **来源偏好模型**：分别按语义、字母和位置迁移来源分数变化；也包括来源选项变化、朝来源最终选项推动的模型。
- **物理难度基线**：在置信度之外加入接收图像的精确净力矩、相对力矩差、重量差、距离和之差。
- **重量与来源力矩模型**：分别使用接收距离和来源距离预测响应。
- **增量检验**：同一行为基线加入接收者重量项，是否比不加这一项更准；再与加入来源力矩项比较。
- **真实图片变化基线**：另外询问模型真实修改后的接收图像，用其候选分数变化预测内部干预的结果。

最后一种基线多使用一次反事实图片前向，单独命名为 natural_response。它的分数在封存预测之前获得；只有这个预测器可以读到这些分数。其他预测器不使用反事实图片分数、干预后状态或干预结果。

精确物理量来自实验生成器，属于有结构信息的诊断模型，不能写成从任意未标注图片自动获得的纠错器。普通置信度和来源偏好模型不使用接收者真值。实验支持的构造本身使用物理规则，这与预测器直接读取正确答案是两回事。

## 校准、验证与统计单位

每个模块 32 个校准家族、96 个验证家族；两模块共 256 家族，两个模型共用这份支持。一个家族中的来源、接收背景、映射、层和随机方向始终放在同一划分内。

场景在运行模型前生成。排除当前 Drive 项目中可找到的历史 JSON/JSONL 场景、manifest、support 和 family 文件，并把左右镜像视为同一几何。校准、验证和两个模块之间也排除这些几何重叠。排除清单会导出。

**排除范围以首次建档时实际可见的文件为准。** 仅放在下载目录或未解压 ZIP 中的历史场景不会自动进入清单；如需纳入，在第一次运行前解压至项目历史结果目录，或填写 EXTRA_HISTORY_ROOTS。不要把“相对已索引历史文件无重叠”写成对所有历史图像的绝对保证，也不声称这是新的物理取值范围或新渲染风格。

校准阶段做五折家族交叉验证，选择一个表现最好的简单基线，随后冻结全部预测器。验证阶段：

1. 只运行来源和未干预接收输入；另取真实反事实输入的独立基线。
2. 保存每次干预的预测及整个预测文件的校验值。
3. 全部预测封存后，才允许第一次验证集内部干预。
4. 断点续跑核对配置、输入、状态、预测与已保存结果；不重新拟合。

主要指标是三个候选**分数变化的预测误差**，越小越好。每个家族先汇总，再计算家族 bootstrap 区间和配对符号翻转检验；每模型 18 项预设比较一起做 Holm 校正，两个模型完成后对共 36 项比较统一校正。校正后的双侧检验与效应方向一起解释。

最终答案另报预测是否一致、是否改变，以及“原错变对、原对变错、换成另一个错误答案、选项不变”的识别表现。没有出现的事件保留 0 次，召回率留空；不能用大量未变化案例掩盖无法预测修复。宏平均指标只覆盖有定义的类别，必须与事件数量一起读。

映射、来源选项是否稳定、原始分数差距分层、距离交叉表属于预设的次要分析。分数差距的分组边界只由校准集确定。32/96 是这一轮的计算预算，不是已经由真实效果量证明充分的样本量。

## 对照与结果边界

每个模块每个划分的四分之一家族，在所有条件上额外运行四个随机方向。随机写入匹配 BF16 实际发生的状态改动，允许相对误差不超过 2%。失败情况单独列出，并同时保存全部尝试和所有对照均匹配成功的家族分析。

真实图像对照分别报告：模型对原图是否正确、对反事实图是否正确、内部干预是否跟随反事实真值、内部干预是否只是与模型的反事实回答相同。后两者不能合并。

结果可能支持的故事包括：

- 来源字母模型能提前预测普通条件的改善及映射冲突后的损害：说明这一指定操作的效果可由输出偏好解释，不能仅以改善准确率认证物理计算。
- 接收距离项在新家族上提供超过行为、来源力矩等基线的增量，并与自然物理反事实相容：支持所测操作具有使用接收条件的功能性组合能力。
- 只能预测分数变化，却不能可靠预测选项翻转：主张限于分数层面。
- 没有预测增益，或自然反事实端点本身表现很弱：保留阴性和边界结果，不推出模型完全没有物理计算。

这个实验的价值取决于竞争解释能否被区分及预测是否获得支持，不能提前保证阳性或提高多少中稿概率。也不能把一般性的“干预成功不等于机制正确”宣称为首次发现。
